# Decodelabs-internship-project

## 📌 Overview
This project analyzes gadget sales data containing 1,200 customer records to uncover trends in revenue, customer behavior, and product performance.

## 🎯 Objectives
- Analyze sales trends
- Identify top-performing products
- Understand customer behavior
- Create interactive dashboards

## 🛠 Tools Used
- Excel
- SQL
- Tableau

## 🧹 Data Cleaning
- Removed duplicates
- Handled missing values
- Standardized formats
- Corrected inconsistencies

## 📈 Key Insights
- Highest sales recorded in june
- chairs generated the most revenue
- Customer retention improved over time

## 📊 Dashboard
The dashboard provides:
- Revenue analysis
- Sales trends
- Product performance
- Customer insights
