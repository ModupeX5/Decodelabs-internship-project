GADGET SALES PERFOMANCE ANALYSIS


Project Overview

This project analyzes gadget sales data to identify customer behavior, revenue trends, product performance, and overall business insights.
The dataset contains 1,200 records of sales transactions collected across different time periods.

Objectives

• Analyze total sales revenue
• Identify top-performing products
• Track monthly/weekly sales trends
• Understand customer purchasing behavior
• Discover high-profit categories
• Create visual dashboards for insights

* Tools Used
• Microsoft Excel
• SQL 
• Tableau / Power BI
• GitHub

Data Cleaning Process
The following cleaning steps were performed:
• Removed duplicate records
• Checked and handled missing values
• Corrected data formats
• Standardized column names
• Verified numerical consistency
• Prepared dataset for visualization

Key Insights
